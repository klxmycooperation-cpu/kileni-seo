# Источники иконок

- Telegram: официальный логотип из [Telegram Press](https://telegram.org/press), файл `t_logo.svg`.
- MAX: силуэт и фирменные цвета из официального [брендбука MAX](https://go.max.ru/brandbook), файл `Max colored.svg`.
- Телефон и e-mail: собственные служебные пиктограммы KILENI.
- WhatsApp: фирменные цвета и узнаваемая пиктограмма канала; показывается только при заполненном `PUBLIC_WHATSAPP`.
