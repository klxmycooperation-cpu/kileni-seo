Этот список является обязательной финальной сверкой перед передачей и публикацией.

- [x] Скриншоты 1–2: кнопка «Обсудить исправления» читается в Dark, Signal и Light, включая hover/focus/disabled.
- [x] Скриншоты 1, 3–4: заменить профессиональные названия простыми; технический термин допустим только после человеческого названия и с коротким объяснением.

## Письма, контакты и админка

- [x] Во всех новых формах удалён сбор Telegram; допустимы телефон и e-mail. Legacy-записи Telegram остаются читаемыми в админке.
- [x] Письмо с аудитом имеет HTML и plain-text версии: бренд, домен, дата, содержание отчёта, безопасная кнопка и видимая ссылка, телефон и MAX.
- [x] SPF, DKIM и DMARC проверены отдельно. Оформление письма не выдаётся за способ гарантированно убрать спам.
- [x] Аватар отправителя не обещается средствами HTML: отдельно настраивается профиль ящика или BIMI после DMARC.
- [x] После входа `/admin` открывает обзор: новые обращения, аудиты, брифы, понятные статусы и графики только по реальным данным.
- [x] Если настоящая статистика посещений ещё не собиралась, админка не выдумывает её; источник и период каждого показателя подписаны.
- [x] Проблемы аудита в admin detail описаны теми же понятными формулировками, что в клиентском отчёте.
