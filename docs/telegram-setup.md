# Настройка Telegram-уведомлений

Telegram используется для оперативного уведомления о новой заявке, расчёте, брифе или запуске аудита. Сохранение данных не зависит от доступности Telegram: при ошибке заявка остаётся в SQLite, а результат отправки записывается в `notification_events`.

## 1. Создать бота

1. В Telegram откройте официальный аккаунт `@BotFather`.
2. Выполните `/newbot`, задайте имя и username.
3. Сохраните выданный токен в менеджере секретов. Не вставляйте его в issue, чат команды, скриншот или репозиторий.

Если токен был раскрыт, отзовите его через BotFather и сразу замените в production.

## 2. Подготовить чат

Для личного чата отправьте боту `/start`. Для группы добавьте бота и отправьте в группе любое сообщение, которое он сможет получить. Для канала боту потребуются права на публикацию.

Для получателя `@myownmuz` именно этот аккаунт должен сначала открыть созданного бота и нажать Start. Затем используйте числовой `message.chat.id` этого диалога: Bot API не гарантирует отправку личному пользователю по username.

Chat ID можно получить из ответа Bot API `getUpdates`. Не сохраняйте токен в истории shell: временно задайте его в текущем сеансе или выполните запрос из защищённого окружения.

```bash
read -s TELEGRAM_TOKEN
export TELEGRAM_TOKEN
curl --fail --silent --show-error \
  "https://api.telegram.org/bot${TELEGRAM_TOKEN}/getUpdates"
unset TELEGRAM_TOKEN
```

Найдите `message.chat.id` или `channel_post.chat.id`. У группового чата значение обычно отрицательное. Если обновлений нет, отправьте новое сообщение после добавления бота и повторите запрос.

## 3. Заполнить окружение

В `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=<TOKEN_ИЗ_BOTFATHER>
TELEGRAM_CHAT_ID=<CHAT_ID>
```

Перезапустите web-контейнер после изменения окружения:

```bash
docker compose up -d --force-recreate web
```

## 4. Проверить интеграцию

Отправьте тестовую заявку через публичную форму с явно тестовыми данными. Затем проверьте:

```bash
docker compose logs --since=10m web
```

В админке у сущности должен появиться результат канала `telegram`: `sent`, `failed` или `skipped`. `skipped/not_configured` означает, что одна из двух переменных отсутствует. При `failed` в базе сохраняется короткое техническое описание, но автоматического повторения отправки сейчас нет.

## Какие данные уходят в Telegram

Сообщение может содержать имя, контакт, выбранную услугу, домен аудита или диапазон расчёта. Поэтому:

- используйте закрытый рабочий чат с ограниченным составом;
- включите двухфакторную защиту для администраторов чата;
- не пересылайте сообщения во внешние чаты;
- учтите Telegram в политике обработки данных и договорных требованиях;
- удаляйте бывших сотрудников и лишних ботов из группы.

Файлы брифа через Telegram не отправляются. Они остаются в приватном хранилище и доступны только из админки.
