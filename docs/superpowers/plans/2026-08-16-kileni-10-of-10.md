# KILENI 10/10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Превратить текущий KILENI в визуально сильный, понятный и доказательный сайт агентства, сохранив реальный crawler, формы, данные, маршруты и подтверждённые кейсы.

**Architecture:** Существующий Next.js App Router и backend остаются. UI пересобирается через сфокусированные Server/Client Components и один новый слой дизайн-токенов; audit API принимает прежний контактный контракт, но сервер сам задаёт лимит 100 страниц. Цены и публичные контакты остаются централизованными, а EN не получает числовые цены без явно утверждённой конфигурации.

**Tech Stack:** Next.js 16, React 19, TypeScript, SQLite/Drizzle, Vitest, Playwright, Axe, SVG/CSS animations.

На момент старта репозиторий не имел ни одного коммита, а весь проект и посторонние материалы были untracked. Ветка `redesign/kileni-10-of-10` создана, но автоматический baseline commit всего каталога сознательно не выполняется: это могло бы включить несвязанные и чувствительные пользовательские файлы. Коммиты возможны после явного определения состава baseline.
