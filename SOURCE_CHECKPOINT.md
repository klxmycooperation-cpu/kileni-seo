# Контрольная копия опубликованных исходников

Эта ветка сохраняет исходники уже опубликованного выпуска `20261008-mobile`.
Это не новая публикация и не замена ветки `main`. Последующие доработки сайта
не входят в эту зафиксированную копию автоматически.

- Основа Git: `a7729bd00eef1b397c0c557c5587f21cd03bac33`.
- Источник: замороженная папка `package-verified2/source` опубликованного выпуска.
- Проверены все 430 файлов исходников по размеру и SHA-256 release-manifest.
- В Git включены 417 файлов из этого набора. По существующему `.gitignore`
  исключены 13 генерируемых файлов: `next-env.d.ts` и 12 публичных PDF/DOCX
  в `public/downloads/generated/` (создаются командой `generate:briefs`).
  Они сохранены в исходном замороженном пакете, но не добавлены в историю Git.
- SHA-256 исходного release-manifest.json:
  `2fa3f1992c96546cfb6cfe6475790fb2488e20b9ff5c6ca3ab4b5dcff775539c`.
- Next.js Build ID опубликованного выпуска: `re5ppvpNo0HmO-93DWXiQ`.

Git сохраняет текстовые файлы с обычной нормализацией окончаний строк.
Документы и тесты основы, не включённые в опубликованный пакет, оставлены
без изменений; их соответствие новому интерфейсу здесь заново не проверялось.
Новая сборка и испытания сайта ради сохранения копии не запускались.
Исходное форматирование кода не исправлялось: в `src/lib/site-assistant.ts`
сохранена в том числе лишняя пустая строка в конце файла опубликованной версии.

В ветку не включены база, заявки, загрузки, секреты, окружение и образы Docker.
Единственная дополнительная настройка вне исходного пакета — запрет
автоматического Vercel-развёртывания именно этой контрольной ветки в `vercel.json`.
Другие ветки этим правилом не изменяются. Для выпуска требуется отдельная приёмка.
